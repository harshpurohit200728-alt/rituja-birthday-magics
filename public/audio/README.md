# Audio Track Info

The application includes a built-in Web Audio API Music Box & Celesta synthesizer in `MusicToggle.tsx` so gentle instrumental music works out of the box with zero external file dependencies.
If you wish to also drop a custom `.mp3` track here (e.g., `public/audio/gentle-bday.mp3`), `MusicToggle.tsx` supports optional HTML5 `<audio>` playback as well.
