# Rituja — A Little World Made Just for You ✨

An interactive, multi-scene birthday storybook website built for Rituja.

## Quick Start & Deployment Commands

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally for Development
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Deploy to Vercel or Netlify
- **Vercel:**
  ```bash
  npx vercel --prod
  ```
- **Netlify:**
  ```bash
  npx netlify deploy --prod --dir=dist
  ```

### 5. Generate Your Custom Ivory & Deep-Green QR Code Card
Once deployed, open your live `https://` website URL, click the **Share Card 🎁** button in the top-right corner, paste your public URL, and click **Generate QR Card ✨** -> **Download PNG ⬇**.
